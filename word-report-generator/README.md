
# WORD报告生成工具 - 退网方案

基于浏览器的离线Word报告批量生成工具，用于根据模板和数据表格批量生成退网方案报告。

## 功能特性

- **纯本地处理**：所有数据处理均在浏览器本地完成，无需上传服务器，保护数据安全
- **模板保护**：严格保护模板原有格式，仅替换占位符，样式/表格/页眉页脚保持不变
- **批量生成**：支持根据Excel数据批量生成多份报告
- **图片插入**：支持从压缩包中读取图片并插入到报告指定位置
- **实时预览**：模板上传后可预览占位符位置
- **字段映射**：自动匹配模板占位符与数据列

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- 第三方库：
  - xlsx.js - Excel文件解析
  - mammoth.js - Word文档解析
  - jszip.js - ZIP文件处理

## 快速开始

1. 直接在浏览器中打开 `退网报告生成小工具.html` 文件
2. 无需安装依赖，所有资源通过CDN加载

## 使用方法

1. 上传Word模板（.docx格式）
2. 上传Excel数据表格（.xlsx/.xls格式）
3. 上传图片压缩包（.zip格式，可选）
4. 确认字段映射关系
5. 点击"开始生成报告"按钮
6. 下载生成的报告

## 模板占位符格式

- **文本占位符**：`{{字段名}}`
- **图片占位符**：`{{@字段名}}`

## 数据表格要求

- 第一行为说明行（自动跳过）
- 第二行为表头行（字段名）
- 第三行开始为数据行

## 图片压缩包结构

```
图片压缩包.zip
├── 文件夹1/
│   ├── image1.jpg
│   ├── image2.png
│   └── ...
├── 文件夹2/
│   ├── image1.jpg
│   └── ...
└── ...
```

## 兼容性

- 支持Chrome、Firefox、Safari、Edge等现代浏览器
- 建议使用Chrome浏览器以获得最佳体验

## 注意事项

- 所有数据处理均在本地完成，不会上传到任何服务器
- 建议使用规范的占位符命名，避免特殊字符
- Excel表头名称需与模板占位符名称对应（不区分大小写）
