# WORD报告生成工具 - 使用指南

## 📋 项目简介

这是一个纯前端实现的本地WORD报告批量生成工具，可以帮助您快速根据Word模板和Excel数据表批量生成报告。

**主要特点：**
- ✅ 纯本地处理，无需后端服务器
- ✅ 支持批量生成多份报告
- ✅ 自动识别模板占位符
- ✅ 支持图片文件夹压缩包上传
- ✅ 一键打包下载所有报告

## 📁 文件准备

### 1.1 Word模板文件

**要求：**
- 格式：`.docx`（Word 2007及以上版本）
- 包含占位符标记

**占位符格式：**
- 文本字段：`{{字段名}}`
- 图片字段：`{{@图片字段名}}`

**示例模板片段：**
```
报告编号：{{report_no}}
报告日期：{{report_date}}
项目名称：{{project_name}}

项目现场照片：
{{@site_photos}}

签名：
{{@signature}}
```

---

### 1.2 Excel数据表格

**要求：**
- 格式：`.xlsx` 或 `.xls`
- 第一行为说明（会自动跳过）
- 第二行为表头（字段名）
- 数据从第三行开始

**字段命名规则：**
- 列名必须与模板中的占位符名称一致（不包括花括号）
- 建议使用英文或拼音，避免特殊字符
- 图片文件夹名字段填写对应的文件夹名称

**示例表格：**

| report_no | report_date | project_name | site_photos | signature |
|-----------|-------------|--------------|-------------|-----------|
| REP-001 | 2024-01-15 | 智慧园区项目 | photos_001 | sig_zhangsan |
| REP-002 | 2024-01-20 | 工业园区项目 | photos_002 | sig_lisi |

---

### 1.3 图片文件夹压缩包

**要求：**
- 格式：`.zip`
- 压缩包内包含多个文件夹
- 每个文件夹对应模板中的一个图片占位符

**文件夹结构：**
```
images.zip
├── photos_001/
│   ├── 01_entrance.jpg
│   ├── 02_building.jpg
│   └── 03_facility.jpg
├── photos_002/
│   └── ...
└── sig_zhangsan/
    └── signature.png
```

**命名规范：**
- 文件夹名称必须与Excel表格中对应字段的值完全一致
- 支持的图片格式：JPG、JPEG、PNG、GIF、BMP、WebP
- 建议使用数字前缀控制图片顺序（如 `01_xxx.jpg`）

## 📖 使用步骤

### 第一步：上传Word模板

1. 点击「上传Word模板」区域
2. 选择您的 `.docx` 模板文件
3. 系统自动解析模板中的占位符
4. 预览区域会显示模板内容，占位符会高亮标记

### 第二步：上传数据表格

1. 点击「上传数据表格」区域
2. 选择您的 `.xlsx` 或 `.xls` 文件
3. 系统自动读取表格数据
4. 字段预览区域会显示字段映射关系

### 第三步：上传图片文件夹

1. 点击「上传图片文件夹」区域
2. 选择包含所有图片文件夹的 `.zip` 压缩包
3. 系统自动解析并显示文件夹结构
4. 确认文件夹名称与表格数据匹配

### 第四步：检查字段映射

1. 查看「字段预览与映射」表格
2. 确认所有占位符都已正确映射
3. 如有未匹配的字段，检查命名是否一致

### 第五步：生成报告

1. 点击「开始生成报告」按钮
2. 查看生成进度和日志
3. 等待所有报告生成完成

### 第六步：下载报告

1. 单个下载：点击报告文件直接下载
2. 批量下载：点击「下载所有报告」按钮
3. 系统会打包所有报告为ZIP文件下载

## 🎯 占位符命名建议

为了确保系统能够正确匹配字段，建议遵循以下命名规范：

### 推荐格式
```
# 使用下划线分隔
project_name
report_date
site_photos
signature_image

# 使用驼峰命名
projectName
reportDate
sitePhotos
signatureImage
```

### 注意事项
- 避免使用中文作为占位符名称
- 避免使用特殊字符（除下划线外）
- 保持命名风格一致
- 字段名称区分大小写

## 🔧 常见问题

### Q1: 字段映射显示"未匹配"怎么办？
**A:** 检查Excel表格的列名是否与模板中的占位符名称完全一致（不包括`{{}}`）。注意区分大小写。

### Q2: 图片没有正确替换怎么办？
**A:** 确保图片文件夹压缩包的文件夹名称与Excel表格中对应字段的值完全一致。

### Q3: 生成的报告格式错乱怎么办？
**A:** 当前版本生成的报告为基础文本格式，复杂排版可能不完全保留。如需保留复杂排版，建议手动复制模板内容。

### Q4: 可以生成多少份报告？
**A:** 理论上没有限制，但建议单次不超过100份。大量生成时可能需要较长时间。

### Q5: 浏览器会保存我的数据吗？
**A:** 不会。所有数据都在本地浏览器内存中处理，不会上传到任何服务器。关闭浏览器后数据会清除。
