# WORD报告生成工具 - 使用说明

## 一、工具概述

本工具用于根据Word模板和Excel数据表格批量生成退网方案报告。支持后端模式进行Excel OLE嵌入。

## 二、快速启动

### 方式一：双击启动（推荐）

1. 找到 `start_server.bat` 文件
2. 双击运行该文件
3. 命令行窗口会显示：`Server running on http://localhost:8080`
4. 打开浏览器访问 `http://localhost:8080`

### 方式二：命令行启动

```bash
cd C:\Users\Administrator\Documents\trae_projects\test1\word-report-generator
python server.py
```

## 三、准备工作

### 1. Word模板文件

创建一个.docx格式的Word文档作为模板，在需要替换内容的位置插入占位符：

- **文本占位符**：`{{字段名}}`
  - 示例：`{{小区名称}}`、`{{退网日期}}`、`{{负责人}}`

- **图片占位符**：`{{@字段名}}`
  - 示例：`{{@现场照片}}`、`{{@设备图片}}`

- **Excel嵌入占位符**：`{{excel:标识符}}`
  - 示例：`{{excel:table1}}`

### 2. Excel数据表格

准备一个.xlsx或.xls格式的Excel文件，格式要求：

| 行号 | 内容 | 说明 |
|------|------|------|
| 第1行 | 说明文字 | 自动跳过 |
| 第2行 | 表头 | 字段名称需与模板占位符对应 |
| 第3行及以后 | 数据 | 每行对应一份报告 |

### 3. 小区数据压缩包（后端模式）

包含Excel和图片的ZIP压缩包：
```
小区数据.zip
├── excel/
│   └── 数据.xlsx
├── Environment_images/
│   └── 环境照片.jpg
└── RemovedEquipment_images/
    └── 设备照片.jpg
```

## 四、操作步骤

1. 启动后端服务（使用 `start_server.bat`）
2. 打开浏览器访问 `http://localhost:8080`
3. 上传Word模板、Excel数据表格、图片压缩包
4. 如需使用OLE嵌入，启用"后端模式"开关
5. 点击"开始生成报告"按钮

## 五、后端模式说明

后端模式使用Python服务进行Excel OLE嵌入：

1. 确保已启动后端服务
2. 点击页面右下角的"后端模式"开关
3. 系统会自动检测服务状态
4. 启用后会使用后端API处理Excel嵌入

## 六、常见问题

### Q1：后端模式提示服务未启动？
**解决方案**：确保已运行 `start_server.bat`，然后点击"已启动，检查状态"

### Q2：无法访问页面？
**解决方案**：确保服务器正在运行，访问地址为 `http://localhost:8080`，不是直接打开HTML文件

### Q3：Excel嵌入失败？
**解决方案**：确保安装了Microsoft Office或WPS

## 七、服务管理

- **启动**：双击 `start_server.bat`
- **停止**：在命令行窗口按 `Ctrl+C`
- **状态检查**：访问 `http://localhost:8080/api/health`
