# 微信小程序 - 待办清单

一个简洁美观的微信小程序待办清单应用，支持云开发数据库存储。

## 功能特性

- ✅ 微信一键登录
- ✅ 添加新任务
- ✅ 标记任务完成/未完成
- ✅ 删除任务
- ✅ 任务筛选（全部/待完成/已完成）
- ✅ 数据保存在微信云开发数据库
- ✅ 任务统计面板
- ✅ 简洁美观的UI设计

## 快速开始

### 1. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择本项目目录
4. 填写AppID（可以使用测试号）

### 2. 开通云开发

1. 在微信开发者工具中，点击工具栏的"云开发"按钮
2. 按照提示开通云开发服务
3. 记录下你的环境ID

### 3. 配置云环境ID

修改 `app.js` 文件中的云环境配置：

```javascript
wx.cloud.init({
  env: '你的环境ID',  // 替换为你的云环境ID
  traceUser: true,
})
```

### 4. 创建数据库集合

1. 进入云开发控制台
2. 选择"数据库"
3. 创建集合 `todos`
4. 设置集合权限为"所有用户可读，仅创建者可读写"

### 5. 上传并部署云函数

1. 在微信开发者工具中，右键点击 `cloudfunctions/login` 文件夹
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 6. 编译运行

点击微信开发者工具的"编译"按钮，项目即可运行。
